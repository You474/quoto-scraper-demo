  • 无服务端：项目是 CLI，不监听端口，不存在服务端错误面（Get-NetTCPConnection 无需检查）。

规避：取证统一用 cmd /c "python ..." 或先 $ErrorActionPreference='Continue'，判据取「真实退出码 + 末行输出」双条件。
